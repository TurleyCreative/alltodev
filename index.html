Accessibility Statement
We want everyone to be able to use this site, regardless of ability. It can be operated fully by keyboard, including reaching and interacting with map markers, zones and lightbox popups, and using Escape to close any open dialog. Screen reader users are supported through labelled buttons and dialogs, live status updates, descriptive text alternatives for map markers, and an accessible "Map Contents" list that lets you browse scenes, markers and zones in text form without needing to interact with the map itself. If you're not able to click the map to leave feedback, you can enter a location manually instead. We've also checked colour contrast across the site and provide a light/dark theme option. We're continuing to improve accessibility here — if you run into any difficulty using this site, please get in touch via the feedback form and we'll do what we can to help.
